# Student Performance Analytics System

Student: Prarthana Ramesh, B.Tech CSE (AI & ML), HITS Chennai

# Objective
To analyse student marks automatically and find totals, averages, grades, pass/fail results, subject-wise performance and top students.

# Technologies Used
Python, NumPy, Pandas

# Dataset Description
`students.csv` has 20 student records with Student_ID, Name, Department, marks in 5 subjects (Python, Maths, Physics, English, Data_Structures) and Attendance.

# Implementation
1. Read the CSV file using Pandas.
2. Calculated total and average marks using NumPy.
3. Gave grades using a function (A+ >= 90, A >= 80, B >= 70, C >= 60, D >= 50, else F).
4. Used loops to find Pass/Fail (pass = 40 or more in every subject).
5. Found the highest, lowest and class average.
6. Did subject-wise analysis and found the top 5 students.

# Key Features
- calculate_total() and calculate_average()
- get_grade() and add_grades()
- add_result()
- Subject-wise average and best subject
- Top 5 students


# Final Outcome
The program shows the grade and result of every student, the class average, the number of students who passed and failed, the best subject and the top 5 students.
